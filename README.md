# 太鼓计分研究所

一个完全在浏览器内运行的 TypeScript + Vite 概念验证工具；不需要服务端或数据库，也不会上传输入。

## 启动与检查

```bash
npm install
npm run dev       # Vite 开发服务器
npm test          # Vitest 领域测试
npm run build     # 类型检查与生产构建
```

## 部署到 GitHub Pages

仓库已包含 GitHub Actions 工作流。推送到 `main` 或 `master` 后，它会自动安装依赖、构建 `dist/` 并发布到 GitHub Pages；也可以在仓库的 **Actions → Deploy to GitHub Pages → Run workflow** 手动触发。

首次使用时，请进入仓库 **Settings → Pages**，将 **Build and deployment / Source** 设为 **GitHub Actions**。部署成功后，页面通常位于 `https://<用户名>.github.io/<仓库名>/`。Vite 使用相对资源路径，因此 fork 或重命名仓库时不需要修改 `base`。

也可以在本地确认 Pages 构建结果：

```bash
npm run build
npm run dev -- --host 0.0.0.0
```

## 两种模式

- **由成绩推算分数范围**：输入良、可、不可、连打敲击数和计分制。因为不可会重置连击，只有判定数量而没有判定顺序时，工具使用动态规划计算所有排列的准确上下界；上下界相同则显示确定分数。
- **由总分反推成绩组合**：输入目标总分、总音符数、最大连打数，可补充已知不可数。搜索由总音符数约束的良/可/不可组合及 `0…最大连打数`，并分页展示前 50 条。候选若依赖排列，会同时标明上下界；这类候选还需要实际判定顺序核对。

## 规则与单位

本 PoC 采用**旧作街机风格计分规则**（并非现行作品或特定谱面的官方验算器）：

- 非真打的良分数为 `初项 + 阶段系数 × 公差`，向下取整到 10；连击前置数量为 `0–9 / 10–29 / 30–49 / 50–99 / 100+` 时，系数分别为 `0 / 1 / 2 / 4 / 8`。
- 可为同阶段良的一半并向下取整到 10；不可为 0 并将连击归零。
- 真打中良固定 1000 分、可固定 500 分、不可为 0；初项和公差不参与计算。
- 连打输入单位是**有效敲击次数**，每次 100 分；它不增加普通音符数。所有分数单位均为“分”。
- 初项、公差、判定数等输入必须是非负安全整数。良、可、不可及总音符数上限均为 9,999，连打上限为 9,999，总分上限为 9,999,990，初项和公差上限均为 9,990。

## 当前限制

- 不处理大音符、气球、芋、黄连打的版本差异、谱面分歧、天井分、奖励分或作品间规则差异。
- 反推为有界搜索而不是无约束枚举；为保持浏览器响应速度，总音符数可输入至 9,999；超过 60 时必须填写至少两个已知判定数量，以避免候选爆炸。一个分数位于某组合的排列上下界，并不保证区间内每个整数都可由某一排列取得，因此标记为“范围”的候选需要按实际判定顺序进一步核对。
- 本工具用于研究与估算；若需核对特定游戏版本，请先确认该版本的初项、公差、连击阶段、取整和连打规则。
